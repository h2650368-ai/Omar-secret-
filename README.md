# SECRET LETTER — رسالة سرية لصاحب عمري

## الملفات
- `index.html` — محتوى الموقع والرسالة.
- `style.css` — التصميم والحركات والألوان.
- `script.js` — فتح الجواب، الكتابة حرفًا حرفًا، المؤثرات والنجوم.
- `music.mp3` — اختياري؛ أضف ملف موسيقى تملك حق استخدامه بهذا الاسم لتفعيل زر الصوت.

## تشغيل الموقع
افتح `index.html` في المتصفح لمعاينته، أو ارفع الملفات الثلاثة إلى مستودع GitHub.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع (نفس المستوى، وليس داخل مجلد فرعي).
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر ظهور رابط الموقع في صفحة Pages.

## تعديل الرسالة
افتح `script.js` وابحث عن `const messageParagraphs` وعدّل الفقرات الموجودة بين علامتي الاقتباس. أبقِ كل فقرة كسطر نصي بين `"..."`، واستخدم علامات الاقتباس الإنجليزية داخل الكود فقط عند الحاجة مع الهروب منها.
لتعديل الكلام المخفي، افتح `index.html` وابحث عن `id="extraMessage"`.

## الموسيقى
أضف ملف MP3 مناسبًا باسم `music.mp3` إلى نفس المجلد. الموسيقى لا تعمل تلقائيًا؛ الزائر يضغط زر الصوت أولًا، احترامًا لإعدادات المتصفح.

## قسم أسئلة الصاحب
أضفت 10 أسئلة مع حقول للإجابة ونتيجة لطيفة حسب عدد الخانات التي تم ملؤها. النتيجة لا تصحح الإجابات نفسها؛ لو عايز تصحيحًا فعليًا، أضف إجاباتك الصحيحة داخل JavaScript.
